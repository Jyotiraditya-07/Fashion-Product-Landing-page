# 🧥 Fashion Product Landing Page

This is my **second web development project** created using only **HTML and CSS**. It’s a clean and modern product landing page designed to showcase a stylish fashion item with emphasis on layout, readability, and interactivity.

## 🚀 Features

- 🧭 Custom top navigation bar with icon integration
- 💬 Descriptive product headline and supporting text
- ✨ Interactive hover effects on action items
- 🎨 Elegant color palette and consistent typography
- 🖼️ Full-width background image showcasing the product
- 🔗 Actionable links for cart, product details, and shipping
- 🔲 Smooth element spacing using Flexbox
- 🛍️ Responsive-friendly structure ready for mobile optimization

## 📁 Project Structure

project/ ├── index.html # Main HTML file ├── style.css # Custom CSS styling


## 🧠 What I Learned

- Structuring landing pages for product promotion
- Using **Flexbox** for dynamic horizontal layouts
- Implementing hover animations to enhance UX
- Working with background images for visual emphasis
- Improving visual hierarchy through consistent sizing and spacing
- Adding **Remix Icons** to enhance interactivity and aesthetics

## 🔧 Technologies Used

- HTML5
- CSS3
- [Remix Icon](https://remixicon.com/) (via CDN)
